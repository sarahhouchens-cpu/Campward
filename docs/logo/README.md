# Campward logo assets

Four SVG logo variants for the Campward site, all sharing the same icon (a tent with a small strand of glowing string lights) and wordmark styling.

## Files
- **campward-logo-full.svg** — Icon stacked above "Campward" wordmark, with "PLAN · PACK · GO" tagline below. Use for hero sections, landing pages, splash screens, or anywhere there's vertical space.
- **campward-logo-compact.svg** — Smaller icon + wordmark only, no tagline. Use in footers, sidebars, or anywhere space is limited.
- **campward-icon-only.svg** — Icon alone inside a solid dark green circle. Use for favicon, browser tab icon, app icon, or social profile image.
- **campward-logo-on-dark.svg** — Outline/monochrome version of the compact lockup in off-white, on a dark green background. Use wherever the logo needs to sit on a dark green or similarly dark surface (e.g. a dark footer band, dark mode header).

## Colors used
- Forest Moss `#3F4E3B` — primary dark green (tent line work, icon-only background, dark mode background)
- Sage `#8A9A5B` — tent fill
- Trail Dust `#A87C4F` — string light wire, tagline text
- Bone `#F4EFE4` — light bulb fill, off-white text on dark backgrounds
- Warm glow `#FFF8E7` — soft radial glow behind each light bulb (used only in the full lockup)

## Typography
- Wordmark and tagline: Georgia (serif) as a stand-in — swap for Fraunces or Lora in production per the site style guide.

## Usage notes
- Do not stretch non-uniformly — all icons should scale proportionally.
- The icon-only version is the only one designed to work at very small sizes (16–32px, e.g. favicon).
- The "on dark" variant should be used instead of the full-color version any time the background is Forest Moss or similarly dark — the full-color version's dark green line work won't have enough contrast on a dark background.
